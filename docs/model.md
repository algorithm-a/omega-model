# Описание модели



## 5D-пространство состояния



Каждая ветвь мультивселенной имеет вектор состояния из 5 компонент:



    state_vector = (x, y, z, w, v) из R^5, ||state_vector|| = 1



Компоненты — абстрактные «измерения», не физические.



## Мультивселенная



Дерево ветвей, построенное от корня (root) с ветвлением

branching_factor (по умолчанию 3) и глубиной max_depth (по умолчанию 3).

Итого 40 ветвей (1 + 3 + 9 + 27).



Каждая ветвь имеет:



- state_vector — 5D-состояние

- depth — глубина в дереве

- impulses — накопленные кваанты

- coherence — локальная когерентность



## Кваанты сознания



На каждой ветви генерируется CONSCIOUSNESS_DENSITY кваантов

(по умолчанию 4). Каждый кваант — комплексная амплитуда:



    amplitude = intensity * exp(i * theta)



где:



- theta зависит от state_vector, номера кваанта и шума

- intensity = (1 / (1 + depth)) * (1 + 0.15 * n)



«Кваант сознания» — математическая сущность, не частица.



## Метрики



**Когерентность (фазовая):**



    C = |sum(amplitude)|^2 / sum(|amplitude|^2)



Принимает значения в [0, 1]. C = 1 — все фазы совпадают.

C = 0 — фазы случайны.



**Энтропия Шеннона:**



    S = -sum(p_i * log(p_i)), где p_i = |amplitude_i|^2 / sum(|amplitude_j|^2)



Принимает значения в [0, log2(N)].



## Действие агента



micro_action(action) получает скаляр в [-1, 1] и искажает

векторы всех ветвей:



    a = clip(action, -1, 1)

    для каждой ветви:

        bias = a * 0.7 * sign(mean(state_vector))

        distorted = state_vector + bias

        state_vector = distorted / ||distorted||



a = +1 — усиливает доминирующий знак среднего — растёт C.

a = -1 — усиливает противоположный знак — падает C.

a = 0 — ничего не делает.



## Цикл



    run_cycle():

        если мультивселенная пуста: big_bang()

        для каждой ветви: simulate_experience()

        вычислить C и S

        если C >= OMEGA_THRESHOLD: coherence_collapse()

        иначе: enhance_simulation()



coherence_collapse() — находит лучшую ветвь, делает её новой

сингулярностью и запускает новый big_bang.



## Reward-функции



**life — удержание точки:**



    reward = -|C - TARGET_C| - 0.1 * |S - TARGET_S|

    TARGET_C = 0.3, TARGET_S = 6.0



**order — рост когерентности:**



    reward = dC * 100.0



## Гиперпараметры



| Параметр | Значение | Описание |

|---|---|---|

| BRANCHING_FACTOR | 3 | Ветвление дерева |

| MAX_DEPTH | 3 | Глубина дерева |

| CONSCIOUSNESS_DENSITY | 4 | Кваантов на ветвь |

| DECOHERENCE_NOISE | 0.05 | Шум в фазе |

| OMEGA_THRESHOLD | 0.1017 | Калибруется автоматически |

| TARGET_C | 0.3 | Целевая когерентность |

| TARGET_S | 6.0 | Целевая энтропия |

| TRAIN_STEPS | 10000 | Обучение PPO на сид |

| EPISODE_LENGTH | 50 | Шагов в эпизоде |

| SEEDS | 30 | Сидов эксперимента |
