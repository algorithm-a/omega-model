# Omega-Model RL Prototype

Вычислительный прототип **5D-циклической Omega-модели** — игрушечной математической формализации метафоры Omega-точки Тейяра де Шардена и Типлера.

**Важно:** это **игрушечная модель**, не физическая теория. «5D» — пространство состояния, «кваанты сознания» — математические сущности, а не частицы.

## Что это

Модель описывает **циклическую вселенную**:

1. **Big Bang** — из сингулярности разворачивается 5D-сфера.
2. **Expansion** — генерируется дерево ветвей (все возможные миры).
3. **Experience** — в каждой ветке симулируются «кваанты сознания».
4. **Omega Check** — проверяется глобальная когерентность.
5. **Collapse** — если когерентность выше порога, идеальная ветка сжимается в новую сингулярность.

**Когерентность** `C = |Σψ|² / Σ|ψ|²` — основная метрика.

## v11: эволюция ветвей

**Идея:** ветви **рождаются** и **умирают** динамически:
- **`energy`** — растёт от когерентности, падает со временем.
- **`prune_branches`** — удаляет мёртвые ветви.
- **`spawn_branches`** — создаёт новые от root.
- **Reward** — популяционный (`alive / initial + C - S/12`).

## PPO vs MCTS

**MCTS (18.32) > PPO (16.30) на 12%.**

**Интерпретация:**
- **MCTS** — классический поиск, не требует обучения.
- **PPO** — нейросеть, требует 30000 шагов обучения.
- **MCTS** лучше в **маленькой** среде (40 ветвей).
- **PPO** в **100 раз быстрее** на инференсе (MCTS требует deepcopy).
- **PPO масштабируется** на большие среды, MCTS — нет.

**Вывод:** в малых средах классический поиск конкурентен; для больших сред нужны нейросети.

| N | random | ppo | mcts | Победитель |

- **PPO стабильнее** по std между сидами.
