# Omega-Model RL Prototype

Вычислительный прототип **5D-циклической Omega-модели** —
игрушечной математической формализации метафоры Omega-точки
Тейяра де Шардена и Типлера.

**Важно:** это **игрушечная модель**, не физическая теория.
«5D» — пространство состояния, «кваанты сознания» —
математические сущности, а не частицы.

## Что это

Модель описывает **циклическую вселенную**:

1. **Big Bang** — из сингулярности разворачивается 5D-сфера.
2. **Expansion** — генерируется дерево ветвей (все возможные миры).
3. **Experience** — в каждой ветке симулируются «кваанты сознания».
4. **Omega Check** — проверяется глобальная когерентность.
5. **Collapse** — если когерентность выше порога, идеальная ветка
   сжимается в новую сингулярность и цикл повторяется.

**Когерентность** `C = |Σψ|² / Σ|ψ|²` — основная метрика.
Она равна 1 при полной согласованности фаз и 0 при полной декогеренции.
Не зависит от числа ветвей — Omega нельзя достичь наращиванием
количества.

## История версий

Четыре версии RL-агента, каждая улучшала сигнал:

| Версия | Файл | Что нового | t (trained vs random) | final_C |
|---|---|---|---|---|
| v3 | `code/omega_unified.py` | PPO baseline | +7.41 | 0.0116 |
| v4 | `code/omega_recurrent.py` | + LSTM память (RecurrentPPO) | +8.50 | 0.0261 |
| v5 | `code/omega_growth.py` | + reward `growth` (`+C - 0.1·|S-6|`) | +12.40 | 0.0195 |
| v6 | `code/omega_branch_action.py` | + векторное действие `(3,)` | **+13.40** | **0.0256** |

Все версии: **30 сидов**, парные t-тесты по сидам, эпизод 50 шагов,
обучение PPO — 10 000 шагов на сид.

**Прогресс:** `t` вырос с **7.41** (v3) до **13.40** (v6) — почти в 2 раза
за четыре итерации.

## Ключевое открытие

Скрипт `code/check_omega_max.py` показал: **среда может дать `C = 1.0856`**
при параметрах `branching_factor=5`, `max_depth=5`, `noise=0.005`
(без RL, только за счёт `enhance_simulation`).

**Но RL работает в фиксированной среде** (`branching=3`, `depth=3`,
`noise=0.05`) и достигает только `final_C ≈ 0.02`.

Попытка разрешить среде расти **каждый шаг RL-эпизода** привела к
**деградации**: `C=0`, `S=0`. Среда не успевает адаптироваться.

**Вывод:** RL улучшает сигнал (`t` растёт), но `final_C` застревает
около 0.02, потому что **RL не управляет параметрами среды**.
